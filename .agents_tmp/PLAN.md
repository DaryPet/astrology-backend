# 1. OBJECTIVE

Создать полноценное fullstack веб-приложение для астрологии с следующим функционалом:
- Ввод пользовательских данных (имя, дата рождения, время, место)
- Построение натальной карты (зодиакальный круг, планеты в знаках, аспекты)
- AI-расшифровка карты на основе загруженных астрологических книг
- Расчёт солярных возвращений (Solar Returns)
- Расчёт транзитов планет
- Расчёт синастрий (совместимость двух карт)
- Тёмная космическая тема UI

# 3. APPROACH OVERVIEW

## Основные принципы

1. **Модульность** — бэкенд и фронтенд разделены, могут развиваться независимо
2. **Астрологическая точность** — используем проверенные библиотеки (swisseph)
3. **AI на основе книг** — система RAG (Retrieval-Augmented Generation) для поиска релевантных фрагментов из загруженных книг
4. **Простота запуска** — всё работает из коробки с SQLite

## Почему этот подход

- React + Vite — быстрая разработка и hot reload
- FastAPI — асинхронный, быстрый, auto-documentation
- SQLAlchemy — единый интерфейс для SQLite/PostgreSQL
- SQLite — не требует установки, сразу работает

# 4. IMPLEMENTATION STEPS

1.2 Настроить виртуальное окружение Python

## Этап 2: Backend — Базовая инфраструктура

2.1 Настроить SQLAlchemy с SQLite
2.2 Создать модели: User, NatalChart, Book, ChartInterpretation
2.3 Создать API эндпоинты:
   - POST /api/users — создание пользователя
   - POST /api/charts — расчёт натальной карты
   - GET /api/charts/{id} — получение карты
   - POST /api/charts/{id}/interpret — AI-интерпретация
   - GET /api/charts/{id}/solar-return — соляр
   - GET /api/charts/{id}/transits — транзиты
   - POST /api/synastry — синастрия двух карт
   - POST /api/books — загрузка книги (текст/PDF)

2.4 Реализовать расчёт натальной карты:

2.6 Реализовать расчёт текущих транзитов
2.7 Реализовать расчёт синастрии (аспекты между двумя картами)
